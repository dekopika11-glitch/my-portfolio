# dekopika ポートフォリオ

学生エンジニア dekopika の自己紹介・制作物紹介サイトです。

**公開URL：** https://my-portfolio-virid-nine-80.vercel.app

## 掲載している制作物

- [シフト管理アプリ](https://github.com/dekopika11-glitch/shift-app-demo)（Next.js / Supabase）: [デモ](https://shift-app-demo-sigma.vercel.app)
- [TypeChase](https://github.com/dekopika11-glitch/typing-chase)（JavaScript）: [デモ](https://dekopika11-glitch.github.io/typing-chase/)

## 技術スタック

Next.js 15（App Router）/ React 19 / TypeScript / Tailwind CSS v4 / react-icons。Vercel でホスティングしています。

## ローカルでの起動

```bash
npm install
npm run dev
```

http://localhost:3000 で表示されます。制作物・スキルの一覧は `src/app/page.tsx` 冒頭の `works` / `skills` 配列を編集すると更新できます。
